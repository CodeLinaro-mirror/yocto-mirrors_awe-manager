# Resource View

{{name.awe_mgr}} does not store/persist data on the target platform during its lifecycle. 

It does, however, require a correctly deployed and configured {{name.awe_awc_db}}. This container includes at a minimum the AWC index file, a main AWB and optionally preset AWB files.

The AWC index file of {{name.awe_awc_db}} is created by {{name.awctool}} scripts that work on target files generated by AWE Designer. After this file has been generated (on PC), it has to be copied (together with the main AWB file) to appropriate locations on the target platforms. 

!!! note
    The detailed documentation of the process of generating the {{name.awe_awc_db}} is outside the scope of this document. 

The [awe_AWC][awe-awc-overview] component is used internally to encapsulate the reading, parsing and handling of the AWC data. This paves the way to potentially change the internal AWC structure/format without modifications to {{name.awe_mgr}}.
