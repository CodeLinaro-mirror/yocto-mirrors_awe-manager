# AWE-Manager Design Documentation

This is the design documentation of AWE-Manager and it's sub-components.

It is derived from markdown files within the GIT code repository; it's close to and up-to-date to the code and it is administered in the typical GIT review and pull-request process.

Each component, AWE-Manager as well as every sub-component, has a documentation that is split into:

- **Overwiew** - generally describes the component.
- **Context View** - illustrates where to find the component in the system; which other components work with it.
- **Structural View** - if the component has an internal structure then it is mentioned and described here.
- **Behavioral View** - shows how to interact with the module, or how the component's internal state behaves.
- **Resource View** - mentions which system resources (files, ...) the component needs or administers.
- **Requirements** - lists requirements of or design decisions for the component.
