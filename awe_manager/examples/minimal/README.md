# Example for Minimal Usage

This CMake package only contains a small sample program that serves as "documentation" of API usage - see `minimal.c`.

Steps to run this executable:

- do build as usual - there will be an executable `./awe_manager/examples/minimal/awemgr_minimal` inside the build directory

- start AWE Server executable on PC - the example assumes it runs under WSL and connects to the host PC

- start `./awe_manager/examples/minimal/awemgr_minimal`
